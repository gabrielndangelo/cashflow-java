# ☕ MinasInCentro CoffeeShop
Um pequeno fluxo de caixa desenvolvido em **Java**, inspirado em conhecimentos que adquiri no curso de Assistente Administrativo.

A proposta foi simples: pegar uma lógica que eu já conhecia utilizando planilhas e tentar representá-la através de um programa.

> **Entradas − Saídas → movimentação do caixa**

## 💰 O sistema
O programa simula o controle diário do caixa de uma cafeteria fictícia.

Através de um menu no console, é possível:

* registrar entradas;
* registrar saídas;
* informar o tipo de cada movimentação;
* acompanhar o total de entradas e saídas;
* consultar o saldo atual;
* visualizar a diferença em relação ao saldo inicial;
* identificar um resultado positivo, negativo ou neutro;
* gerar um relatório ao encerrar o caixa.

### Exemplo

```text
==========================
 MinasInCentro CoffeeShop
==========================
Fluxo de caixa diário
ENTRADAS: R$ 335,00
SAÍDAS: R$ 90,00
SALDO FINAL: R$ 745,00
=============================
Diferença: R$ 245,00
STATUS: Lucro
```

## ☕ Por que "MinasInCentro"?

O nome é uma brincadeira com o contexto de uma cafeteria e com o próprio **Java**. A empresa é fictícia. 
O objetivo do projeto não é representar um sistema comercial completo, mas criar uma situação concreta para praticar programação sem transformar o exercício em apenas cálculos isolados.

## 🧠 O que pratiquei

Neste projeto trabalhei principalmente com:

`Scanner` 
• `switch/case` 
• `if/else` 
• `do/while` 
• variáveis 
• acumuladores 
• operações aritméticas 
• entrada e saída de dados 
• formatação com `printf`

O `do/while` mantém o caixa em funcionamento até que o usuário escolha encerrá-lo, enquanto os acumuladores registram os totais 
das movimentações realizadas durante a execução.

## 📚 Contexto
Este projeto faz parte da minha etapa de consolidação dos fundamentos de Java antes de avançar para **Programação Orientada a Objetos**.
A ideia surgiu a partir do conteúdo de **Fluxo de Caixa** estudado no curso de Assistente Administrativo, no qual esse tipo de controle
foi trabalhado utilizando Excel.

Aqui, o desafio foi outro:
**transformar o conceito administrativo em lógica de programação e implementá-lo com Java básico.**
